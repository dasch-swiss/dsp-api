# datacite-4.3-schema.json

Origin: dsp-repository `shared/fair/testdata/schemas/datacite-4.3-schema.json`, itself the DataCite schema
repository's `kernel-4.3/datacite_4.3_schema.json` at commit `2ade77951cf2`, patched by dsp-repository's
`download-schemas.sh`: the `resourceTypeGeneral` and `dateType` enums are widened to 4.6, all `uniqueItems` are
removed and `schemaVersion` is a `const`.

The schema declares JSON Schema draft-07.
